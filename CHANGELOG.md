## [Unreleased]

### Added
- Initial project scaffolding
- C++20 Windows service with SCM integration
- PDH, battery, thermal, and process collectors
- SQLite storage with WAL mode and migration runner
- 1-minute and 15-minute metric aggregation
- Power pipeline with Wh accumulation
- cpp-httplib HTTP server with REST API and WebSocket
- Vite + Preact + uPlot web dashboard
- WiX v4 MSI installer definition
- GitHub Actions CI/CD pipelines
- Comprehensive documentation
